// turbo-all
1. Добавить все изменения в индекс:
   `git add .`
2. Создать коммит с автоматическим сообщением или сообщением от пользователя:
   `git commit -m "Auto-commit: update from AI assistant"`
3. Отправить изменения в удаленный репозиторий:
   `git push`
